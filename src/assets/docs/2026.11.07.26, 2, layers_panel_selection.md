A hidden `<defs>` can now be selected in the Layers panel. I made the change in `9-atoms-layers-panel.ts`.

The cause was `selectLayersAtom`, which dropped any row id that `isHiddenOrLocked` flagged. That check treats `display="none"` as unselectable, so a hidden `<defs>` was filtered out before the selection was set. `<defs>` is never drawn, so its display doesn't matter.

The fix adds `isLayerRowBlocked`:
- For a `<defs>` row, it blocks only if the `<defs>` or one of its ancestors is locked. A hidden `<defs>` or a hidden ancestor no longer blocks it.
- Every other row keeps the original hidden-or-locked check.

Lock still applies to `<defs>`, since its lock button is still shown.
