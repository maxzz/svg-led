**Cursor**

The rotate cursor is now on a 24×24 viewBox, and I updated the code that depends on the old 32-unit size.

Changes in `src/ui/cursors/tailwind-cursors.ts`:
- `viewBox`, `width`, and `height` are now 24.
- The drawing didn't fit in 24 units: its points spanned about 5.5 to 27.5. I scaled every coordinate by 0.75 around the center, so the glyph's center moved from (16.5, 16.5) to (12, 12). The stroke widths are unchanged, so the 1px black line still covers one pixel.
- The doc comment now says the hotspot is (12, 12).

Changes in `src/ui/cursors/rotate-glyph.ts`:
- `ROTATE_GLYPH` is now `{ size: 24, hotX: 12, hotY: 12 }`. The hotspot previously sat at (16.5, 16.5), so it would have been off-center in the smaller box.

The rotation transform and the CSS cursor value both read from `ROTATE_GLYPH`, so they pick up the new center automatically. Nothing else in `src` referenced the old size, and the linter reports no errors. I didn't run the test suite or check the cursor visually in the app.
