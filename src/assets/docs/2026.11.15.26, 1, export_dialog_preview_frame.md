The export preview now draws the exported image inside a frame of its real size, so you can see both the canvas and where the artwork sits in it.

The frame keeps the export's aspect ratio and is fitted into the preview. Width is labeled along the bottom edge and height along the right. For SVG, React, and data URI exports, that size is the viewport (absolute width and height when they are set, otherwise the viewBox). For PNG it is the pixel size, including scale. The drawing is painted into that rectangle, so empty space in the viewBox and alignment from `preserveAspectRatio` stay visible. The checkerboard is only the image itself.
