I don't see the screenshot in your message, so I'll look through the code for the Hint area and the Properties popup.

I couldn't see the screenshot in your message, so I'm assuming the red rectangle marks the Hint line under the toolbar.

**Why it shifts:** In `0-all-workspace.tsx`, the toolbar, `Island_Hint`, and `Island_PropertiesPopup` are all children of one `flex flex-col gap-2` container. The popup has no position of its own, so its top edge is whatever sits above it. When the hint renders, it takes its height plus a `gap-2` (8px) gap, and the popup moves down. The shift also happens when the hint's text wraps to a second line, and when the hint is turned off, the popup jumps back up.

**Options**

1. **Reserve a fixed-height hint slot (recommended, smallest change).** Always render a wrapper with a fixed height (for example `h-4`), even when the hint is off or empty. Add `truncate` or `whitespace-nowrap` so wrapping can't change the height. The popup never moves, and the hint stays in its own row, so it can't overlap the popup. The cost is a small empty band when the hint is off.

2. **Move the hint out of the stack.** Put the hint at the bottom center of the canvas, next to Zoom/Undo and Help, and remove it from the top column. The popup no longer depends on it, and the two can't overlap because they sit in different corners. The cost is that the hint is no longer under the toolbar, so the layout changes.

3. **Take the hint out of flow and offset the popup.** Make the hint `absolute` under the toolbar and give the popup a fixed top offset equal to the toolbar height plus the reserved hint height. This works, but it relies on hard-coded pixel values that break if the toolbar height changes. It's also easy to get wrong for the no-overlap requirement.

4. **Make the popup absolutely positioned.** Pin it with a fixed `top` and leave the hint in flow. This is the same as option 3 with more fragile coupling, so I wouldn't choose it.

I'd go with option 1 because it fixes the jump and guarantees no overlap with the fewest changes. If you'd rather have the hint somewhere else entirely, option 2 is the cleanest. I haven't changed any files yet. Which do you want?
