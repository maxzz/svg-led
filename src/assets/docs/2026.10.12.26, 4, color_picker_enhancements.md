**User**

Currently, the Color Picker does not allow for opacity selection; even if a different model—such as HSL—is chosen, the value is still converted to a hexadecimal color, which is not ideal. 
Ideally, if the HSL model is selected, the color should be displayed as a CSS function, given that SVG supports these formats. 
It is also desirable to have support for newer color formats and the ability to specify the opacity of the selected color. 
This functionality should be available for both stroke and fill colors, while the separate opacity parameter should remain unchanged, as it is applied as an HTML attribute.
	
If implementation using built-in browser features is not possible, a popular and reliable library should be selected and integrated into the project. Ideally, the library should be actively maintained and updated, as well as widely used; if there are multiple options, please propose them and outline their respective advantages and disadvantages.	

It is also worth noting that it won't be used immediately when the application is displayed and loaded; in other words, its loading can be deferred until the Color Picker is used for the first time.
But it is not mandatory, so the final decision if it makes sense rests entirely with you.

Also, take a look at the Excalidraw project (https://github.com/excalidraw/excalidraw) to explore the implementation details.

## Library choice

Browser built-ins can't do this. `<input type="color">` is hex-only with no alpha, and canvas `fillStyle` normalizes everything to hex or rgba. Neither gives you components in other spaces.

| Option | Weekly downloads | Latest release | Coverage | Trade-offs |
|---|---|---|---|---|
| **colorjs.io** (chosen) | ~9.6M | 0.7.1, Jul 2026 | Full CSS Color 4: lab, lch, oklab, oklch, hwb, and more | Larger (~28 kB gzip). Lazy-loaded, so the cost is only paid when the picker opens. |
| culori | ~3.7M | 4.0.2, Apr 2026 | Full modern spaces | Smaller and tree-shakeable. Fewer built-in conveniences. A reasonable fallback. |
| react-colorful | ~6.5M | 5.8.1, Sep 2026 | Picker UI only; hex, rgb, hsl | Very small and popular, but no lab/lch/oklch. You'd still need a parser. |
| tinycolor2 | ~14M | 1.6.0, Jul 2023 | No lab/oklch | Widely used, but no longer maintained. |
| vanilla-colorful | ~0.6M | 2022 | Picker UI only | Stale. |
| @uiw/react-color | ~0.2M | 2.10.3, May 2026 | Picker UI; limited models | Smaller community. Doesn't give you the color math. |

I chose colorjs.io because it's the only option that parses every CSS color syntax and converts between all the spaces you asked for, and it is actively maintained.

## Excalidraw comparison

Excalidraw uses a Radix popover and a hex-only input. Alpha is stored in the hex string (`#RRGGBBAA`), with a separate opacity slider, and it uses tinycolor2 for parsing. Our version differs by keeping alpha inside the color value and by emitting CSS functions. The separate Opacity section still works as before.

## Behavior to know

- Clicking a palette swatch stores a hex value, so the picker switches back to HEX. That follows from deriving the notation from the stored text.
- Hex values quantize alpha to 1/255 on round-trip.
- An unset stroke or fill (`none`) opens the picker as opaque black, because there's no color to read.
- Newer formats such as `oklch()` and `lab()` aren't supported by every SVG consumer. Older editors may not render them. Browsers and modern tools handle them fine.

- **Colors:** 15 cells in Excalidraw's order, with the hotkey letter in each corner (q w e r t / a s d f g / z x c v b). Each family shows the shade currently in use.
- **Shades:** the five shades of the selected family, labeled ⇧1 to ⇧5. Placeholders show when black, white, or none is selected.
- **Hex code:** the `#` field, the color-selector square, and the eyedropper. The eyedropper only appears in browsers with the EyeDropper API (Chromium).

**Behavior**
- Hotkeys work while the palette has focus: `q`–`b` pick a family at the current shade, and `Shift+1`–`Shift+5` pick a shade of the selected family.
- The palette stays open after you pick a color, as in Excalidraw. Before, it closed.
- Escape closes the top popover first: the real picker, then the palette.
- Stroke defaults to shade ⇧5 (`#e03131`) and fill to ⇧2, using Excalidraw's defaults.
