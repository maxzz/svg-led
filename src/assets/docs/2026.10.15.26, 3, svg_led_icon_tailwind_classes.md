**Cursor**

I'll convert each icon's presentation attributes to classes. The codebase already uses Tailwind v4 with `[stroke-miterlimit:10]` and `fill-black`-style utilities, so I'll follow that pattern.

I converted `fill`, `stroke`, and `strokeMiterlimit` to Tailwind classes in all nine icon files. The linter reports no errors.

The mapping I used:

- `fill="currentColor"` → `fill-current`
- `fill="#000"` → `fill-black`
- `fill="none"` → `fill-none`
- `stroke="#000"` → `stroke-black`
- `strokeMiterlimit={10}` → `[stroke-miterlimit:10]`, the same arbitrary-property form the codebase already uses in `27-dnd-target.tsx`

Tailwind v4 has no `stroke-miterlimit` utility, so the arbitrary form is needed. I left the existing `fill-*`/`stroke-*` classes on the root `<svg>` and the `<rect>` elements in `cc-1-1` untouched, and I didn't change any geometry or `title`/`className` handling.

I haven't rendered the icons to check them visually.
