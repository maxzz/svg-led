I added a custom dash array text field to the "Stroke style" section. It sits below the Solid / Dashed / Dotted buttons, and the TypeScript check passes with no errors in that file.

How it behaves:

- **Input:** Type numbers separated by spaces or commas, e.g. `6 2 1 2`. The value is written to `stroke-dasharray` as typed, so it is not scaled by stroke width the way the presets are.
- **Commit:** Enter or blur applies it. Escape reverts to the current value.
- **Empty or `none`:** Clears the dash array (solid line).
- **All zeros:** Also treated as solid, which matches SVG's behaviour.
- **Invalid input:** Negative numbers or non-numeric tokens are rejected and the field reverts.
- **Mixed selection:** The field shows "Mixed" as a placeholder. Blurring it without typing does nothing, so it won't clear the dashes on every selected node.
- **Sync:** The field shows the normalized value of the selection and updates when the value changes elsewhere, such as through undo or a preset click.

The changes are in `1-style-sections.tsx`: a new `DashArrayField` component plus `normalizeDashArray` and `parseDashArray` helpers, and a `KeyboardEvent` import from React. I haven't run the app to check the layout or interaction by hand.
