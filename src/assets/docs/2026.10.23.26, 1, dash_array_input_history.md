For the Dash array input element in the Properties panel should feature a button on the right that displays a history of previous entries. 
From this drop-down list, a user can select an existing value or remove one—hovering over an item in the list should reveal an 'X' icon on the right to delete that specific entry. 
The number of items in the list must be limited to 5. 
This component functions as a MRU (most recently used items).

In this scenario, the invalid value must remain in the input field; 
the only way to exit this state is by pressing the Escape key or selecting for "Stroke style" another value form "Custom".
If the input process is exited via the Escape key, the field should revert to its previous value (the value that existed before the user selected "Custom'; if no such previous value exists, the "Stroke style" will become "solid").

Implement this new control (in the style of a combo box) in a separate file (so it can be reused for other cases), using either Jotai or Valtio for state management (whichever is more suitable in this case); if animations are required, use the Motion library.
