**Why the gain is small:**
- Each cursor is already defined once, as a module constant. The data-URI string is built once when the module loads. Nothing rebuilds it per render or per pointer move.

**What it would gain:** one place to define each cursor, referenced by class name, with the data-URI text kept out of the JavaScript.
