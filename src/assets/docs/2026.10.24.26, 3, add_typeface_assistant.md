**User**

Are there still any browsers that require the WOFF format, or can we reduce the bundle size by excluding it?

---

**Cursor**

Almost no browsers still need WOFF. Every browser released in the last several years supports WOFF2, and the main exception is Internet Explorer 11, which Microsoft no longer supports. Some very old Safari and Opera Mini versions also lack WOFF2. I'm working from memory here, not a live compatibility table, so check caniuse.com if you need exact numbers.

Dropping the `.woff` files would save only disk space on the server, about 40 KB across the three subsets. Browsers never download them, so visitors would see no difference in load time or bandwidth.

Removing them isn't simple either. `@fontsource/assistant` doesn't offer a WOFF2-only import, so you'd have to write your own `@font-face` rules or add a post-build step that deletes the files.

I'd keep the current setup, since the fallback costs nothing for visitors.

```css
@import "@fontsource/assistant/600.css"; /* Semi-Bold */
@import "@fontsource/assistant/700.css"; /* Bold */
```

Then use them with Tailwind's `font-medium`, `font-semibold` and `font-bold` classes on elements that use the Assistant family. Those classes map to weights 500, 600 and 700, which the imports above now provide.
