# Scaling operation tooltip
_Exported on 11/13/2026 at 13:46:05 PST from Cursor (3.30.14)_

---

**User**

Just as a small tooltip showing the rotation angle is displayed during a rotation operation, a similar tooltip should be shown during a scaling operation to indicate the extent to which the size is being increased or decreased.

---

**Cursor**

Now let me look at the rotate tool, where the readout atom is set, and the scale/resize tool.

The rotate readout is a jotai atom that the overlay renders as a small label. I'll generalize that label and add a parallel readout for scaling, so both drags share the same tooltip.

Now the select tool: import the new atom, publish the scale readout during resize, and clear it on release.

Next, the overlay: rename the tooltip to a generic drag tooltip that reads either readout.

A scaling drag now shows a small label next to the pointer, the same way rotation does. It shows the new size as a percentage of the original, and it disappears when the drag ends. I haven't run the app or the tests, and only ran lint on the three edited files, which came back clean.

What the label shows:
- **Corner handles, uniform scale** (or Shift to keep the aspect ratio): one value, e.g. `120%`.
- **Corner handles, non-uniform scale**: both axes, e.g. `W 120% · H 80%`.
- **Edge handles**: only the axis being changed, e.g. `W 120%` or `H 80%`.

If you drag past the opposite side and the object flips, the label shows the magnitude without a sign.

Changes:
- `src/tools/tool-2-select/3-rotate.ts`: the readout type is now `DragReadout`, and there's a new `scaleReadoutAtom`.
- `src/tools/tool-2-select/0-factory-select.ts`: `resizeMatrix` also returns the per-axis scale factors. The resize move updates `scaleReadoutAtom`, and pointer up and deactivate clear it. A new `formatScale` builds the label text.
- `src/components/1-workspace/1-canvas/3-overlay/2-overlay-selection.tsx`: `RotateTooltip` is now `DragTooltip`, which shows whichever readout is active. Placement is the same as the rotation label.
- `src/tools/tool-2-select/index.ts`: exports `scaleReadoutAtom`.

If you'd rather show absolute dimensions (e.g. `120 × 80`) instead of percentages, that's a small change in `formatScale`.
