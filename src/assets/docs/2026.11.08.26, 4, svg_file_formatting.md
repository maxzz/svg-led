- **Formatter** (`src/svg-core/3-serialize/6-format-svg-text.ts`): one tag per line, indented two spaces per level. Attribute values, comments, CDATA, processing instructions and the doctype are kept exactly. Content of `text`, `tspan`, `style`, `script`, `foreignObject` and similar elements is left untouched, so text and CSS don't change.
- **Malformed SVG:** if the source doesn't parse, the formatter returns nothing, the text stays as it is, and a toast says there are syntax errors.
- **Editor wiring** (`1-monaco-host.tsx`): the action is a normal edit. Code sync parses it back onto the canvas on the same debounce as typing. The caret stays on the same token after formatting.
- **Tests**: 8 new cases in `src/svg-core/tests/format-svg-text.test.ts`.

The formatter is my own, not a library, so its output style is a judgment call. Tell me if you want a different indent width or attribute wrapping.
