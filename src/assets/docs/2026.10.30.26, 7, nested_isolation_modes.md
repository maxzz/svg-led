# Nested isolation mode behavior
_Exported on 10/30/2026 at 20:11:45 PDT from Cursor (3.27.22)_

---

**User**

Now we need to verify the behavior when isolation modes are nested—that is, when an application is already in isolation mode and a user double-clicks an element or newly selected elements, triggering a further level of isolation. 
The navigation panel breadcrumb should display these nested isolation levels. 
Furthermore, when a user clicks on a parent isolation mode label within the breadcrumb navigation panel, the system should return to that parent level, rather than exiting all active isolation modes at once. src/components/1-workspace/7-isolation-breadcrumbs/0-island-isolation-breadcrumbs.tsx

---

**Cursor**

Nested isolation should show each level in the breadcrumb, and clicking a parent label should return only to that level. I’ll start from the breadcrumb island and how isolation depth is stored today.

The breadcrumb already lists ancestor groups and can jump to one of them. I’ll check whether a second double-click actually nests isolation, and whether a parent crumb only steps back to that level.

Nested isolation of a single group already steps back correctly. Isolating a new selection while a group is isolated drops that parent: the breadcrumb becomes only “2 objects,” and Back leaves every level. I’ll keep each isolation entry on a stack so parent crumbs stay and return to that level only.

Nested isolation now keeps every level in the breadcrumb, and a parent label returns only to that level.

Isolating a group, then a selection inside it, used to replace the breadcrumb with a single **2 objects** crumb. The back arrow and the file name both left isolation completely, because a multi-object level had no parent to return to.

Each entry is now its own level. In the drawing that looks like this:

**untitled.svg › group2 › 2 objects › &lt;Polygon&gt;**

- **group2** was opened first.
- **2 objects** is a selection isolated while that group was already open.
- **&lt;Polygon&gt;** is a further double-click inside that selection.

Clicking **2 objects** returns to those two polygons and selects the polygon you had gone into. Clicking **group2** returns to the group and selects those two polygons. The back arrow does the same one step at a time. The file name still leaves isolation entirely.

**Cursor**

Double-clicking outside the current isolation should leave every level at once. I’ll find that gesture and switch it from stepping back one level to exiting isolation completely.

Double-clicking empty canvas currently steps up one level, the same as Esc. That gesture should clear every isolation level, while Esc and the back arrow stay one step.

Double-clicking outside the objects in the current isolation level now leaves isolation completely, at any depth.

A double-click on empty canvas, or on anything dimmed outside the current level, clears the whole stack and returns to the document. A double-click on an object that belongs to the current level still goes deeper. Esc and the back arrow still step up one level, and a parent label in the breadcrumb still returns to that level.
