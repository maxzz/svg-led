---

**Cursor**

Format specifiers are placeholders in the first argument of `console.log` (and `console.dir`, `console.warn`, etc.). Each one consumes the next argument after the format string:

- `%s`: string
- `%d` or `%i`: integer
- `%f`: float
- `%o`: object, with expandable detail
- `%O`: object, with default expandable view
- `%c`: CSS style applied to the text that follows
- `%%`: a literal `%`

On line 78:

```ts
console.log(`%c${name}`, 'font-size: 0.55rem', value.name);
```

- `%c` is the specifier. It consumes `'font-size: 0.55rem'` as CSS for the `name` text.
- `value.name` has no specifier left, so the console prints it after the styled text.

One caveat: because `name` is interpolated into the format string, a `%` in an icon name would be read as a specifier. Icon names here don't contain `%`, so this is harmless. To be safe you could write `console.log('%c%s', style, name, value.name)` instead.
