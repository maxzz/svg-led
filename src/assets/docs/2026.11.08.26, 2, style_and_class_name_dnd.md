**What you can do now**
- **Move a `<style>` between `<defs>` elements, or reorder it:** drag it above or below another top-level item of any `<defs>`, or onto a `<defs>` row to append it at the end.
- **Move a class between `<style>` elements, or reorder it:** drag it above or below another class, or onto a `<style>` row to append it at the end.
- **Cross-`defs` moves:** a class can move into a `<style>` in another `<defs>`.
- **Undo:** each move is one history step, and the code panel updates through the existing sync path.

**How the markup changes**
- A class moves with all of its rules. If a rule is shared, such as `.a, .b{…}`, the other class keeps the rule and the moved class gets its own copy with the same declarations.
- Deactivated classes and declarations move with their prefixes and comments intact.
- A moved item keeps its `deactivated-` state.
