# Collapsed group indicator
_Exported on 11/6/2026 at 19:03:00 PST from Cursor (3.29.9)_

---

**User**

In the Layers panel, it is possible to select an item that resides within a group, which in turn may be nested inside another group that is currently collapsed. 
To indicate that a selected item is contained within a collapsed group (or a nested group structure), a small square should be displayed next to the each group icon—specifically at the end of the line, marked by a circle. 
This square should appear whenever a selected item is present somewhere within that group, regardless of whether the group itself is collapsed or expanded.
This should resemble how it’s done in Adobe Illustrator. @src/components/1-workspace/6-layers-panel

Changes:

- **`9-atoms-layers-panel.ts`**: a derived atom collects the ids of all ancestors of the current selection. A `containsSelectedFamily` atom exposes that per row.
- **`1-1-layer-row.tsx`**: `SelectionCircle` takes a `containsSelected` prop and renders the square when it is true. Regular group rows and the single-object Isolation Mode root both pass it. Plain layer rows never show it.

The marker only appears on group rows, and it doesn't show when a group is selected with nothing selected inside it. The ancestor set is recomputed when the selection changes, so a document edit that moves a selected item without changing the selection may leave the marker stale until the next selection change.
