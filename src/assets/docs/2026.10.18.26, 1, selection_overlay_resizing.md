When one or more objects are selected on the canvas, a bounding box appears, with four handles along its edges for resizing; when the mouse is positioned over one of these handles, the corresponding cursor icon is displayed.

This allows for the scaling of selected elements—which is how it’s currently implemented, and that is, in principle, the correct approach. 
Now, we need to ensure that when the mouse is positioned over one of the edges of this rectangle, the size changes only along the axis perpendicular to that edge (and appropriate cursor is shown). 
Furthermore, we must account for key combinations like Control and Alt, following the pattern used in the Excalidraw project (https://github.com/excalidraw/excalidraw).

**What changed**

- **Edges:** each side of the box has a thin invisible strip between the corner grips. Hovering it shows `ns-resize` on the top and bottom edges and `ew-resize` on the left and right. Dragging moves only that side, and the opposite side stays fixed.
- **Midpoint grips:** I added a visible grip at the middle of each edge, as Excalidraw does, so the perpendicular resize is discoverable. The corner grips are unchanged.
- **Alt:** resizes around the center of the box. On an edge, only that axis stretches from the middle.
- **Shift:** keeps the aspect ratio on corners. It has no effect on edges, since an aspect ratio can't be kept while one axis is fixed.
- **Ctrl:** the existing binding (snap to other objects while dragging) still applies during resize. Excalidraw doesn't use Ctrl for resizing, so I left it alone. Snapping on an edge only snaps along the axis that is moving.
