**User**

An option needs to be added to the dialog to control how selection works: "inclusive" or "exclusive." In "inclusive" mode, 
only those elements on the canvas that fall entirely within the selection marquee will be selected. 
In the opposite mode, an object will be considered selected as soon as any part of it falls within the selection marquee.

This option should be saved as part of the appSettings.

Additionally, if the Control key is held down while selecting, the current "Inclusive/Exclusive" mode is temporarily toggled to the opposite setting; once the Control key is released, the mode reverts to its previous state.
