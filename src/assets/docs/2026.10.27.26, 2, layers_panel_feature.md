**User**

Now it is time to implement a feature called "Layers." 
The Layers panel should be presented as a side panel, similar to the one found in the Monaco Editor. 
Within this panel, SVG layers should be displayed hierarchically—much like in Adobe software (for example, Illustrator and Photoshop).

If an item in the layers panel represents a group, it should be collapsible and expandable.

Layer row:
	Each item in the Layers tree features two icon-based buttons: one controls the item's visibility, 
	while the other (shaped like a padlock) indicates that the layer is locked.
	Next are a thumbnail for previewing the layer and the layer's name.
	Finally, at the end of the row is a selection indicator: a small circle next to each layer that fills with color when the layer is selected.

	The layers tree allows for the selection of multiple items at once.

	A single click on the selection circle selects an item (deselecting any others).

	Furthermore, the user can select (or deselect) several items by clicking and holding the mouse button 
	while dragging the cursor across the desired items—this toggles their selection state.

	The user can also use the Shift key: holding it down selects all items in the range between the first selected item and the one you click on.

	Using Ctrl + click inverts the selection state of an item (without affecting other currently selected items).

	In addition, at the bottom of the "Layers" panel, there should be a bar with buttons that allow you to perform operations on layers—for example, 
	creating a new layer (in this case, a group), deleting a layer, etc.

Isolation mode:
	The "Layers" panel should also support an "isolation mode," in which only the selected parent layer and 
	its nested elements are displayed, while all other layers are hidden from the layer tree; furthermore, 
	interacting on the canvas with objects that are not part of the isolated parent layer becomes impossible 
	until "isolation mode" is exited.

	Isolation mode can be activated by double-clicking an element while the Selection tool is active.

	Moreover, if a user double-clicks an element or a group of elements while in isolation mode, the mode shifts to that specific element—
	in other words, the element that was double-clicked becomes the "parent" for the newly selected isolated group.

	Since isolated groups can be nested, it is necessary to display floating controls at the top that indicate 
	the nesting level of the isolated group—similar to how this is implemented in Adobe Illustrator.

	A user can exit isolation mode by double-clicking outside of any element, pressing the Escape key, or using the control that displays nested groups 
	(often called a "breadcrumb" or "navigation path"); this control allows the user to return not only to the top level but also to one or more levels higher.
	If you need to see screenshots of how this is done in Adobe Illustrator, I can provide them upon your request.
	
	When the application is in isolation mode, it is possible to switch to a mode "Direct selection", and then return to "Selection" mode again not leaving the "Isolation mode". 
	Furthermore, other primitives can be created while in isolation mode; 
	in other words, isolation mode does not in any way restrict the application's functionality compared to when it is not in isolation mode.

	
For state management, the React components should use either Jotai or Valtio—
whichever is more appropriate—instead of standard state management provided by React.
This simplifies component reuse throughout the application.
Implement the new functionality in separate files/folders so that it does not mix with the rest of the code.

Minimize the use of `useCallback` and `useEffect` in React components in favor of Jotai’s `set` atoms and derived atoms (where necessary), or use Valtio’s reactivity where appropriate.

This is a rather significant and important addition to the project, so please reach out if any questions arise or if any points require clarification.

**Layers panel** (Ctrl+Shift+L)
- It slides out from the right edge and can be resized; its open state and width are saved with your settings.
- The tree lists the topmost layer first. Each row has:
  - an eye button and a padlock (dimmed when a parent group is what's hiding or locking it);
  - a chevron for groups;
  - a thumbnail and the name (the element's `id`, otherwise `<Path>`, `<Group>`, and so on);
  - the selection circle.
- Selection:
  - Clicking a circle selects only that layer.
  - Ctrl+click toggles one layer without touching the others.
  - Shift+click selects the range from the last clicked or first selected row.
  - Pressing on a circle and dragging across others toggles each one once.
- Hidden and locked layers can't be selected, either in the panel or on the canvas.
- The bottom bar has Locate, Isolate, New group, Group, Duplicate and Delete.
- Visibility and lock are stored in the SVG as `display="none"` and `data-locked="true"`, so they are saved and can be undone.

**Isolation mode**
- With the Selection tool, double-clicking an element of a group isolates that group. Double-clicking inside an isolated group goes one level deeper.
- Double-clicking a plain element still switches to Points (Direct selection), and you stay in isolation.
- Everything outside the isolated group is dimmed and can't be picked, by any tool or by the marquee and lasso.
- To leave: Escape or a double-click on empty canvas goes up one level. The breadcrumb bar under the toolbar has a back arrow, the file name (exits completely), and each level as a link.
- Isolation stays on when you switch tools. New shapes, pen paths, pasted or dropped SVG, and scraps added to the canvas go into the isolated group, converted into its coordinates.

**Other changes**
- The old group-editing mode is gone. Its atom is now `isolatedGroupIdAtom`. Ctrl+click on the canvas still selects the innermost element; it just no longer changes which group you're in.
- New commands: Enter isolation mode and Exit isolation mode, Hide selection (Ctrl+Shift+H), Lock selection (Ctrl+Shift+K), Show all and Unlock all.
- Select all only picks the selectable children of the isolated group (or of the document).
- New code is in `src/store/6-layers/`, `src/components/1-workspace/6-layers-panel/` and `src/components/1-workspace/7-isolation-breadcrumbs/`. The panel's React components use Jotai write atoms and derived atoms, with no `useEffect` or `useCallback`.
