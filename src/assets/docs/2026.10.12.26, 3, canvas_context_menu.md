- **Empty canvas:** Paste, Copy as PNG (whole drawing), Copy SVG source, Select all, grid/snap/viewBox checkboxes, theme, zoom items. If something is selected, a Deselect item appears at the top, and the selection is kept.
- **On an element, or inside the selection's bounding box:** Cut, Copy, Paste, Copy as PNG, Copy/Paste style, Group (2+ selected), Ungroup (when a group is selected), Convert to path (shapes), Edit points (single path or shape), an Arrange submenu, Flip H/V, Fit selection to viewBox, Zoom to selection, Duplicate, Delete. Right-clicking an unselected element selects it first.
- **Points mode:** Delete points, Smooth/corner, and Back to selection. Delete and Smooth/corner appear only when anchors are selected.

Items that don't apply are hidden rather than disabled, and separators collapse automatically. Commands come from the existing registry, so shortcuts and enabled state match the menus.
