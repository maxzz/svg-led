# Temporary snapping disable feature
_Exported on 11/2/2026 at 19:26:11 PST from Cursor (3.27.22)_

---

**User**

The following functionality needs to be implemented: temporary disabling of snapping while the Alt key is held down.
When dragging an object (in "Selection" or "Partial Selection" mode) or duplicating an object (while moving a copy that has already been created—note that in this case, the Alt key must be released and pressed again to disable snapping), the object moves according to the snapping settings, provided that the snapping feature is enabled.
However, holding down the Alt key should temporarily disable snapping.
Once the Alt key is released, snapping should revert to its original state.

**Cursor**

I'll look through how dragging, duplication, and snapping are wired so Alt can turn snapping off only while it's held.

Alt already starts a copy, so snapping stays on until that press is released and Alt is pressed again. I’ll wire that into object drags in Selection and Direct Selection.

The snap rule is a small pure function, so I’ll move it out of the gesture module so the test doesn’t load the whole editor.

Holding Alt while you move an element turns snapping off, and releasing it turns snapping back on.

- **Selection and Direct Selection.** While you drag an element, Alt suspends both grid snapping and snap-to-objects, including a Ctrl snap. Shift still constrains the axis. Releasing Alt restores whatever snapping was already on.
- **Alt-drag to copy.** That first Alt press still makes the copy, and the copy keeps snapping. Release Alt, then press it again, and snapping turns off for the rest of the drag. Release it once more and snapping returns.
- **Direct Selection.** Dragging the element itself works the same way. Alt on a point or handle is unchanged: it still converts a point or breaks a handle.

I checked this on the open canvas with snap-to-grid on: a plain drag snapped to the grid, Alt pulled the element off the grid, and releasing Alt snapped it back. An Alt-drag copy stayed snapped until Alt was released and pressed again. Those moves were undone, and snap-to-grid is off again. Redo can still replay the test moves until the page is reloaded.
