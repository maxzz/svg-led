**User**

The canvas shape selection mechanism needs to be updated. 
While it works perfectly for individual shapes, using the application becomes simply unbearable when a group is selected or when attempting to select an element within a group—essentially, it is impossible to select any element inside a group.

In the Excalidraw app (https://github.com/excalidraw/excalidraw), the handling of element selection—even within a group—is brilliantly implemented.
Please check their implementation and see how this can be done in our application.

As I understand it, they use a concept where, if a group is selected and you double-click on the shape's outline within that group, the entire group enters "group editing mode"—meaning the bounding box turns into a dashed line and you can select individual elements inside the group; if you then click outside the shape or outside the group's bounding box, that editing mode ends.

However, that is just my understanding; the primary basis for the decision should be the aforementioned application.

In Excalidraw, any click on empty canvas or on an element outside the group ends editing. A click inside the group's box does not keep it alive unless the click lands on a selected element.

**Behavior now:**
- **Click** an element in a group: the whole outermost group is selected, shown with a dashed box.
- **Double-click** that group (or an element in it) once it's selected: enters group editing. The group gets a dashed box, and clicks now select its children one at a time.
- **Click** a child while editing: selects just that child. Nested groups work one level at a time.
- **Click** an element outside the group, or empty canvas: ends editing.
- **Escape** while editing: steps out one level and selects the group. Escape again clears the selection.
- **Ctrl/Cmd+click**: selects the element directly and edits its innermost group. This is Excalidraw's deep select, which I added because it is the quickest way into a group.
- **Double-click** on an ungrouped element still opens points mode, as before.
