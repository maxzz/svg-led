**How it works, modeled on Excalidraw:** I read Excalidraw's `lasso/index.ts`, `lasso/utils.ts`, and the lasso handling in `App.tsx`. Its model is that Alt during a selection drag starts a lasso from the drag origin. Toggling Alt mid-drag swaps modes, and the selection is kept across each swap. I mirrored that in the existing select tool rather than adding a separate tool.

- **Inclusive/Exclusive:** the lasso uses the same Options setting as the marquee, and Ctrl flips it while held.
- **Matching:** elements are tested by their outline (curves are flattened), not just their bounding box. Inclusive needs every point inside the lasso with no edge crossing. Exclusive needs any point inside or any edge crossing. The lasso is simplified before the test.
- **Overlay:** the trail is drawn like the marquee.
- **Help and hint:** Alt is added to the single modifier table, so it appears in the Shortcuts dialog. The tool hint now mentions the lasso.

**Behavior to know about:**
- Alt on an element still drags a copy, as before. The lasso only starts on empty canvas.
- Pressing or releasing Alt mid-drag takes effect on the next mouse movement, not on the key event itself. Excalidraw works the same way.
- Excalidraw does exact curve intersection. Mine uses a flattened outline, so very thin features can occasionally be missed.
