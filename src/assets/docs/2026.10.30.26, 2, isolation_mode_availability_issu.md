Isolation was missing in Chrome because it was decided from a document snapshot taken too early, before your saved file was loaded.

The menu item, the layers-panel button, and the breadcrumb bar all read that snapshot through `atomWithProxy`. The atom is created when the module loads, and at that moment the document is still empty. The saved drawing is loaded a moment later. The built-in browser hot-reloads that module after the drawing is already open, so the same check sees the real file and the item shows up. The two browsers also keep separate saved drawings, but that is not what hid the item here: the path in your screenshot sits inside `<g class="cls_4">`, which is a group isolation can open.
