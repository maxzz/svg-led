# Object highlighting issue
_Exported on 11/13/2026 at 19:42:01 PST from Cursor (3.30.14)_

---

**User**

When the application is in "Select" mode and the mouse is positioned over an object, that object becomes highlighted. 
However, if the object is part of a group, the entire group gets highlighted instead of the specific element the mouse is hovering over. 
This needs to be fixed so that only the individual element within the group is highlighted—not the whole group—with the entire group being selected only when that specific element is chosen.
